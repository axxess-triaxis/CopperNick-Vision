# CopperNick

A sky patrolling agent observer, built as an entry for the **GOSIM (China) Vision OS Hackathon**.

## Concept

CopperNick is an agent that observes and patrols the sky, intended to run on spatial/vision-OS hardware. The specific detection target, sensor pipeline, and runtime platform are still being decided.

## Status

Early scaffold. No architecture, framework, or working code has been committed yet — this repository currently contains only project setup (README, license, gitignore). Treat anything beyond this file as aspirational until an implementation lands.
